# ZulipChat MCP v0.8.0

Not yet released. Built for Clio Coder 0.8 and checked through Clio's own MCP
client on MCP 2026-07-28 against a mock Zulip.

## Highlights

- **Talk to your coding agents from Zulip.** The new `zulipchat-mcp-agents`
  bridge pairs one Zulip bot per agent with a local agent that speaks ACP
  (Clio Coder, OpenCode, Goose, Gemini CLI, and Claude Code or Codex through
  their ACP adapters). DM the bot from any device or mention it in a topic;
  each conversation is one agent session, and the agent asks before risky
  steps (answer `yes` or `no`). Only you and user IDs you list are heard.
  Three commands set it up, and the bridge runs as a login service:

  ```bash
  uv tool install zulipchat-mcp
  zulipchat-mcp-agents add claude
  zulipchat-mcp-agents service install
  ```

  See [Agent bots](../integrations/agent-bots.md).
- **Nothing you send is lost.** Messages land in a queue on disk before
  anything acts on them. A prompt waiting behind a busy turn survives a
  restart and runs then, unless it is over 12 hours old; a turn cut off by a
  restart is reported, never replayed. `listen = "dm"` or `"#channel"` in the
  agent file narrows what the bot hears.
- **Typed approvals only.** A permission request is answered by a message that
  is just `yes`, `ok`, `okay`, `approve`, `no` or `deny`. Reactions do not
  count, so an agent signed in as you cannot approve itself with one.
- **Hand a conversation to Zulip.** `teleport_chat(agent, message,
  session_id)` has the agent's bot DM you, and the bridge resumes that session.
  Inside a bridged agent, `ask_owner` asks you in the same conversation.
- **One call to message a person.** `send_message(type="direct", to="Jaime")`
  resolves the name, refuses ambiguity, and returns a message link.
- **Compact reads.** Message reads default to Markdown and 20 rows, with no
  repeated channel, topic or null fields.
- **A smaller, sharper tool set.** 13 core tools, 45 extended. Thirteen
  redundant or LLM-on-LLM tools and the eight tools of the topic-bound agent
  control plane are gone, and six new Zulip endpoints arrive: topic resolution
  and visibility, reminders, typing, read receipts and edit history.

## Status of the agent bridge

Tested with a fake ACP agent and a mocked Zulip, and in live use against Zulip
with Clio Coder running as a login service: DM and topic turns, interviews,
progress messages and permission requests. Real Claude Code turns ran through it with a mocked Zulip;
OpenCode and Goose were probed for start, session creation and resume. Goose
hangs on an unknown session ID; the bridge then starts a fresh session. The
macOS service is covered by unit tests only.

## Behavior changes

- `search_messages` returns Markdown by default and rows use `from`, `time` and
  `text`. Pass `content_format="rendered_html"` for HTML.
- `teleport_chat` takes an agent bot name instead of `to`, `channel` and
  `topic`. Message other people with `send_message`.
- `get_stream_info` and `get_own_user` moved to the extended set.
- Removed tools: `execute_chain`, `list_command_types`, `construct_narrow`,
  `advanced_search`, `list_instances`, `manage_task`, `send_agent_status`,
  `is_user_group_member`, `toggle_reaction` (use `add_reaction(remove=True)`),
  `agents_channel_topic_ops`, and the three `*_with_llm` analytics tools. The
  server no longer needs `ANTHROPIC_API_KEY`.
- The topic-bound agent control plane is removed: `register_agent`,
  `ensure_agent_session`, `agent_message`, `request_user_input`,
  `wait_for_response`, `poll_agent_events`, `list_sessions`,
  `close_agent_session`, the `zulipchat-mcp-hook` command, the session-operator,
  loop and notifyme skills, and the DuckDB database. Give the agent an agent bot
  instead. `--enable-listener`, `--associate-existing-db` and `--mention-allow`
  are ignored with a warning.

## Clio Coder

Export a declaration with per-tool action classes:

```bash
uvx --from zulipchat-mcp zulipchat-mcp-integrate export --client clio-coder \
  --output-dir /path/to/project --zulip-config-file ~/.zuliprc \
  --zulip-bot-config-file ~/.zuliprc-bot --extended-tools
```

Reads run freely, posting runs without a prompt at default autonomy, and edits,
moves, topic resolution and deletions ask first. See the
[Clio guide](../integrations/clio-coder.md); [Agent bots](../integrations/agent-bots.md)
explains how to reach Clio from Zulip.

## Upgrade

```bash
uvx --refresh-package zulipchat-mcp zulipchat-mcp --version
```
